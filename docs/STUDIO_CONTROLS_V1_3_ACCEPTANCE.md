# v1.3 影片操作與登出驗收（2026-09-01）

## 已更新

- 時長：預設主機上限481幀，由 capabilities 驅動秒數選單、自訂秒數及最長按鈕；更換 FPS 不靜默縮短。主機可另外設定 `LTX_MAX_FRAMES`。
- 比例：9:16、16:9、1:1、4:3、3:4、3:2，以精確且符合模型對齊要求的解析度執行，原有寬高 API 保留相容。
- 登出：過期／重複登出可清除 cookie；跨頁籤 CSRF 輪替最多重試一次；其他頁籤與返回快取頁重查登入。外網可另外選擇「含 Cloudflare 登出」，未取消允許名單或密碼驗證。
- 負面提示詞：未啟用，因只有 Distilled checkpoint／執行器。移除無效輸入框、顯示限制；API 拒絕非空負面提示詞，不假裝生效。Dev 模型與 guided pipeline 尚待另外安裝。
