# 通用影片 Worker v1.1.0 驗收

日期：2026-08-30。範圍僅本機 LTX Local Studio 後端；未修改另一個專案、未合併其 PR、未變更 Cloudflare 政策、未重新部署網站。

## 四個階段

1. **固定通用 API 契約**：`/api/v1/*`、OpenAPI 3.1、契約版本1.1.0。external與project_id可省略；保留舊的明確project_id冪等scope。各專案共用同一套契約，不需GitHub授權或專用路由。
2. **生成能力與參數**：T2V／I2V、版本化compat／preview／landscape／portrait預設組、尺寸、FPS、合法幀數或秒數、seed、音訊、CPU offload、參照強度、生成期限。預檢回完整解析參數；未接通的steps／guidance／LoRA等明確拒絕。
3. **任務可靠性**：SQLite紀錄、重送去重、單GPU名額、階段進度落盤、逾時、取消、正常關機清理、Linux模型父程序死亡防護、重啟標示interrupted、私有暫存後發布。忙碌仍回409，由上游排隊，沒有偷偷重試。
4. **成品技術驗證**：完整解碼、幀數、尺寸、FPS、時間戳、片長、音軌、SHA256；失敗不公開半成品。近黑／近靜止畫面為警告，所有成品仍要求人工審片。

## 自動化測試

- 37項Python測試通過，使用本機LTX的Python環境（PyAV、Pillow、Torch、jsonschema）。包含既有測試類別繼承的相容性案例，不代表37種獨立模型場景。
- 2項Node後端用戶端測試通過，涵蓋認證headers、不跟隨登入重新導向、busy、Range、預檢、取消、分頁與契約讀取。
- 故障注入：程序成功退出但輸出損毀、尺寸／FPS／幀數不符、缺少音訊、靜默程序逾時、執行中取消、驗證階段取消、儲存失敗、磁碟不足與CUDA不可用。
- `git diff --check` 通過。

這些測試不修改模型權重，不訓練模型。CPU合成小影片只作格式／流程測試，不當作AI生成品質證據。
