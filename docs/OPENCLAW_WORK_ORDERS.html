工單提示詞

每張工單三則訊息：執行、驗收、繼續。整段複製貼進 LINE 給老皮；背景任務： 前綴讓它直接進背景（上限 15 分鐘），完成後傳 查詢 JOB-xxxx 取結果。字數已對 LINE 上限（5000）檢查。

使用順序
  1. 先傳一次「開工設定」，讓老皮把規則寫進自己的 USER.md／MEMORY.md。
  2. 傳某張工單的「執行」。它 15 分鐘做不完會停在乾淨狀態並回報；再傳「繼續」直到它自檢全過。
  3. 傳「驗收」— 這是獨立任務，不改程式，逐條 PASS／FAIL，最後一行「可合併」或「退回」。退回就回到步驟 2。
  4. 「可合併」後由你在主機上 ff 合併並 push main；ltx-git-sync 會自動部署。

工作目錄：老皮在 ~/LTX-worktrees/wo-<id> 的獨立 worktree 裡做事；主 checkout 永遠停在 main。若發現主 checkout 不在 main，先 git checkout main 再繼續。

老皮遇到 apt、systemctl、sudo 會先發 【需要核准：OP-xxxx】 區塊 — 那是它自己的規則，回「核准 OP-xxxx」或自己跑它列出的指令。
