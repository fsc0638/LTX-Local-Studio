# v1.2 帳號與模型介面驗收紀錄

日期：2026-08-30。此紀錄描述**程式與隔離測試**，不代表正式網域已切換。

後續更新：同日已啟用免郵件內部帳號模式，完成舊媒體私有化及本機 API／UI 切換。
以下「尚未執行」為先前郵件驗證階段的歷史紀錄；目前狀態請以 [內部測試驗收](INTERNAL_TESTING.md#本次實際啟用與驗收) 為準。

## 已驗證

- 57項 Python 測試：原LTX參數／任務可靠性／技術驗證，新增帳號、單次驗證、未驗證拒絕登入、CSRF、過期、密碼重設撤銷session、跨帳號素材與任務隔離、每日配額、SMTP TLS、搬移拒絕覆寫。
- HTTPS cookie 有 `__Host-` 前綴、Secure、HttpOnly、SameSite=Lax、Path=/、無Domain；HTTP開發cookie不能冒充HTTPScookie。
- 圖片／文字**CPU測試替身**走真正子程序、技術檢查、私有發布、已授權下載；不合格檔案不發布。未安裝模型與未知參數拒絕。
- 原Node後端用戶端2項測試通過，舊Bearer介面仍可使用；JSON/OpenAPI相容測試通過。
- `tsc --noEmit --incremental false` 通過；新增／修改的帳號與模型UI相關檔案通過定向 oxlint。
- 不含私人資料的獨立目錄完成正式模式建置；六個登入／註冊／驗證／重寄／忘記／重設頁面HTTP200，非法模式404。
- 正式模式UI代理→隔離API的HTTP整合：未驗證403 → 驗證不登入 → 新登入cookie → CSRF要求 → 私人檔案僅本人可讀 → 登出後401；安全回應標頭正常。
- 舊媒體搬移僅dry-run：38個檔案待搬移，實際搬移0、刪除0。

`npm run lint` 全專案仍有先前共用UI元件／hooks與舊用戶端的規則問題，本次未改動那些無關元件；不宣稱全庫lint已通過。
