## 需要阿寶做的事

在主機上執行 `docs/PRODUCTION_ROADMAP.md` B0 節「主機（由人執行，需 sudo）」的四行指令：

```bash
sudo apt-get install -y postgresql python3-psycopg
sudo -u postgres createuser kwayrdc                 # peer auth：OS 使用者 = DB 角色，無密碼
sudo -u postgres createdb -O kwayrdc ltx_studio
sudo -u postgres createdb -O kwayrdc ltx_studio_test
```

- **peer auth**：資料庫角色與 OS 使用者同名，因此不需要、也不會儲存任何密碼。
- **只走 unix socket**：DSN 為 `postgresql:///ltx_studio?host=/var/run/postgresql`，不開 TCP；
  完成後 `ss -ltn` 不應出現 5432。
- `ltx-api` 以系統 `/usr/bin/python3` 執行，所以驅動走 apt 的 `python3-psycopg`（3.1），不用 pip。

完成後下達「工單 B0 · 繼續」，即可從第 (2) 步開始。
