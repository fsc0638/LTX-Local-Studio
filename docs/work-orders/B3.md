# B3 自動分鏡

規格：`docs/PRODUCTION_ROADMAP.md` 的 B3 節。分支 `wo/b3`，worktree `~/LTX-worktrees/wo-b3`。

## 已完成

- `lib/breakdown.ts` — 純函式規則引擎，無 import。
  - 切點優先序：段落邊界 ＞ 歌詞行起點（已扣 Bible `lyric_offset_seconds`）＞ `segment_seconds` 上限。
  - 每個切點吸附最近拍點，容差 ±1 拍；吸不到的候選點直接不用，所以切點必然在拍上。
  - 拍距用**中位數**而非平均，少一個拍不會把整條格線撐寬。
  - 無歌詞的鏡標成 `breathing`；每鏡 cue 時間＝鏡起點、`action` 留空、`directing` 帶 Bible 預設。
  - 鏡數上限 60（對齊 `lib/timeline-import.ts` 的 `MAX_CUES`）；超過時放寬 `segment_seconds` 而不是砍鏡，
    否則產出的分鏡無法再匯入時間軸。
  - `mergeBreakdownShots` / `splitBreakdownShot` 會重新編號、重算 cue 與每鏡歌詞歸屬。
  - 每鏡帶穩定的 `id`（由起點算出，非計數器）：合併後接合點以下的 index 全部位移，
    用 index 當 React key 會重用到錯的列。
- `tests/breakdown.test.mjs` — 19 個測試，全過。
  - 驗收案例（166.4 s、104.17 BPM、285 beats、11 段落、40 行歌詞、`segment_seconds=10`）
    產出 **23 鏡**，落在 17–24；無一鏡超過上限；切點全在拍點；11 個段落邊界全部成為切點。
- `components/breakdown-editor.tsx` — 01 分鏡頁。
  - 時間軸：段落色帶、拍點網格（過密時自動抽稀）、能量曲線（`energy_db` 畫成填色包絡，
    不做鏡射波形——那是響度包絡，畫成對稱會假裝它有它沒有的取樣資料）、歌詞行刻度、
    鏡頭區塊可點選。
  - 鏡頭清單：時間範圍、器樂／有詞標籤、切點來源、cue 時間、主要動作輸入、合併／拆分。
  - 三種語系（zh-TW／en／ja）文案齊備。

- `app/page.tsx` — 01 階段接上。
  - 「自動分鏡」按鈕打 `/api/v1/audio/analyze`，拿 beats／sections／energy_db，
    配 Bible 的 `directing`、回應的 `lyric_offset_seconds`、timeline 的 `segment_seconds` 產生分鏡。
  - **分鏡結果直接寫進 `timeline.cues`**，所以「預覽分鏡」沿用 `TimelineControls` 既有那顆，
    沒有第二顆會走味的預覽按鈕。每次編輯（合併／拆分／改動作）也即時寫回，不做「套用」按鈕。
  - 服務不可用（503）顯示說明並繼續運作，不擋生成。三種語系文案齊備。
