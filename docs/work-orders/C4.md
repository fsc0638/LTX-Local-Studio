## 需要阿寶做的事

準備素材，放在**主 checkout** 的 `calibration/`（我從 worktree 用絕對路徑讀）：

```
/home/kwayrdc/LTX Local Studio/calibration/
  <角色A>/   ≥10 張：正面、側面、不同光線，可含幾張 Qwen-Image-Edit 生成的同角色圖
  <角色B>/   同上
  ...        至少 2 個角色
```

- 格式 png／jpg／jpeg／webp，一張一個檔，同一資料夾＝同一角色。
- **同角色配對來自同資料夾、不同角色配對來自跨資料夾**——資料夾分錯，門檻就是錯的。
- 沒有臉的圖（背影、遠景）可以放，腳本會列出來；那些只能靠 DINOv2，UI 會標示。
- 兩個角色不要長得太像；門檻是「分得開不同角色」的邊界，兩個雙胞胎會把它壓到不能用。

## 報告怎麼對到 Bible（下次執行的計畫，先寫下免得重想）

腳本對每個 metric 各給 `thresholds.fpr_01`／`fpr_05`／`eer`（各含 `threshold` 與 `tpr`）：

| 報告 metric | Bible 欄位 | 用途 |
|---|---|---|
| `face_facenet` | `thresholds.cj`（有臉時） | CJ 主路徑 |
| `dinov2_large` | `thresholds.cj_dino` | CJ 無臉退路 —— 尺度不同，不能共用一個數 |
| `clip_vit_l14` | `thresholds.sj` | SJ |
| `lab_mean_delta_e` | 暫不用 | 顏色差異，方向相反（越小越像） |

`fpr_05.threshold` → 預設值；`fpr_01.threshold` → `thresholds.strict.*`；一併寫 `calibrated: true`
與 `eer`、`tpr` 供 UI 顯示。`review_rules.py`／`lib/review.ts` 目前只認 `cj`，要加 `cj_dino`
並依 `method_per_frame` 選用哪條線——這是校準後才會浮現的真需求，C1 時 CJ 兩條路共用 0.80 是暫定。

## 報告 payload 形狀（從腳本讀出，2026-09-06 第二次「繼續」時 `calibration/` 仍不存在）

```
{ root, images, characters: [...],
  missing_faces: ["<path>", ...],                       ← 「無臉圖列出並在 UI 標示」的來源
  metrics: [ { metric: "face_facenet" | "dinov2_large" | "clip_vit_l14" | "lab_mean_delta_e",
               same: {mean, std, worst}, different: {mean, std, closest},
               thresholds: { fpr_01: {threshold, tpr}, fpr_05: {threshold, tpr},
                             eer: {threshold, fnr, fpr} } }
             | { metric, note }                          ← 該 metric 沒有足夠配對時只有 note
           ] }
```

匯入時：找不到 `face_facenet` 的 `thresholds`（只有 `note`）代表素材裡臉太少，`cj` 不寫、只寫 `cj_dino`，
UI 要說明「臉部門檻未校準」而不是整份當成功。`lab_mean_delta_e` 方向相反（越小越像），先不匯入。
